# 리에니에 동·서부 지도 수집 기록

지역 ID `4`, 개발 모드 `/maps/4`용 데이터입니다. [지도 데이터 수집 기준](../../../docs/MAP_DATA_IMPORT.md)을 따릅니다. 대상 이미지는 학원·월광의 제단·리에니에 신수탑과 남쪽 스톰빌 일부를 포함하므로 이미지 범위로 추리고 지역명으로 제한하지 않습니다.

## 출처와 재현

- [LSDL 본편 지도](https://edring.lsdl.kr/map), 확인일 `2026-11-20`. 공개 HTML의 `gmarkers`와 `map.js`를 새로 읽었습니다. 원본 게임 적용 버전은 미확인입니다.
- `source.json`: 이미지 범위의 369개 마커 원본 번호·이름·좌표·코드·설명과 전체 2,096개 좌표 인덱스, 코드 기반 분류, 이미지 SHA-256·해상도·좌표 변환식·정합 지표를 보존합니다. 계정 정보는 저장하지 않습니다.
- `review.json`: 369개 설명의 검토 결과, 획득 목록과 수량·보류 이유, 기존 지역과 겹치는 원본 ID를 기록합니다. 스톰빌과 겹치는 설명은 재검토하고 기존 목록 순서와 보류 기준을 유지했습니다.
- `../generate.mjs`: 원본·검토 자료를 읽어 지역 데이터 블록만 생성합니다. 이미지 해시·후보 ID 집합·설명 검토·수량·현재 코드와 생성 결과를 확인하며 네트워크 요청은 하지 않습니다.

저장소 루트에서 실행합니다.

```bash
node reference-data/maps/generate.mjs liurnia-east-west
node reference-data/maps/generate.mjs liurnia-east-west --check
```

`--check`는 저장한 스냅샷·검토와 코드의 정합성을 확인합니다. LSDL의 이후 갱신이나 사람이 해석한 목록의 의미까지 자동 검증하는 것은 아닙니다.

## 좌표 정합

- 대상 이미지: `src/assets/images/maps/4_liurnia_east_west.webp`, `6000×8400`.
- 원본 타일: `https://edring.lsdl.kr/assets/maptiles/5/tile_{x}_{y}.jpg`, x `4..11`, y `12..24`, 타일 크기 `256×256`. 모자이크 원점 `(1024, 3072)`입니다.
- `u = sourceX × 32 - 1024`, `v = -sourceY × 32 - 3072`를 `source.json`의 2×3 행렬에 넣습니다. 결과 픽셀을 가로 6000·세로 8400으로 나누고 마지막에 소수점 여섯 자리로 반올림합니다. 이미지 밖 좌표를 경계로 잘라 넣지 않습니다.
- SIFT 특징점 최대 16,000개, 대상 이미지 40% 축소, BFMatcher 2근접 비율 0.65로 지형을 매칭했습니다. 대상 점을 원래 해상도로 복원하고 RANSAC 기준 4px로 `estimateAffine2D`를 추정했습니다. 최초 후보 3,964개 중 3,741개를 채택했고, 채택점 잔차 중앙값 약 0.42px·95백분위 약 1.42px입니다.
- 별도로 특징점을 재추출하고 난수 시드 20으로 20%를 분리해 나머지로 변환을 추정했습니다. 후보 3,951개 중 분리한 790개에서 788개가 5px 이내이며, 전체 중앙값 약 0.43px·95백분위 약 1.45px입니다. 나머지 두 개는 큰 불일치점입니다.
- 분리 표본은 이미지 3×3 모든 구역에 분포하고 구역별 95백분위가 약 1.07~1.98px입니다. 학원 건물·동쪽 가도·남쪽 호수 해안의 원본/대상 확대 지형도 대조했습니다. 반복 추출의 매칭 수는 최초 정합과 다릅니다.
- 이는 배경 이미지 정합 검증이며, 원본 개별 마커의 실제 게임 배치나 높이를 확인한 결과는 아닙니다.

## 반영 범위

- 최종 이미지 범위의 후보 369개 모두 반영, 제외 0개·중복 ID 0개입니다. 후보 좌표 인덱스·원본·설명 검토·반영 ID 집합을 비교합니다.
- 원본 코드에 매칭되지 않은 84개도 표시합니다. 원본 제목이 없는 네 마커는 원본 ID·설명을 보존하고 표시명만 `이름 없는 마커`로 둡니다.
- 동부 대지 축복 `LSDL-587`, `588`, `589`는 이름·좌표가 같아도 서로 다른 원본 ID이므로 임의로 합치지 않았습니다. UI에서는 겹쳐 보일 수 있습니다.
- 설명 369개를 검토하고 172개 마커에 획득 항목 347건을 연결했습니다. 원문에 수량이 있는 개별 마커의 목록도 포함합니다. 서로 다른 아이템 종류 수나 지역의 총 획득 수량을 뜻하지 않습니다.
- 기존 림그레이브와 ID 12개, 스톰빌과 75개가 겹칩니다. 같은 장소를 서로 다른 이미지에서 보는 것이므로 각 이미지 좌표로 표시합니다. 기존 세 지역의 ID·좌표·분류·획득 목록은 수정하지 않습니다.
- 학원의 지붕·천장·교실·지하 구간, 월광의 제단과 아래쪽 백금 마을은 원본의 마커·목록을 유지합니다. 별도 층별 좌표나 원본에 없는 상자 위치를 추정하지 않습니다.
- 레날라는 태어나지 않는 자의 거대한 룬·만월 여왕의 추억만 처치 목록에 넣고, 카리아의 왕홀·레날라의 만월은 추억 교환 선택지로 제외합니다. 남쪽 고드릭의 목록도 동일한 구분을 유지합니다.
- 기도서·스크롤·제작서의 해금 목록과 가격, 방울의 판매 해금품, 물방울의 효과 수치, 석검 열쇠 입장 비용을 현 위치 획득 아이템·수량으로 바꾸지 않습니다.
- `LSDL-1518`, `1519`, `2267`처럼 제목에 수량이 들어간 항목도 원본 제목을 보존하고 획득 목록에는 물품명과 수량을 분리했습니다. 재료 6포인트·10포인트 등은 위치 수이므로 아이템 개수로 저장하지 않습니다.

## 보류와 원본의 한계

- 판매 목록, 바레·토푸스·라야·불량배·라티나·셀렌/제렌·디아로스·작은 항아리 등의 진행·대화·구매 조건부 보상은 원문과 검토 이유에 보존합니다. 현재 UI의 일반 획득 목록으로 평탄화하지 않습니다.
- 마누스 셀리스 대교회는 별빛 조각 11개를 넣고 라니 최종 퀘스트 보상인 암월의 대검은 조건부로 보류합니다. 카리아의 서원은 뒤집기 전 목록과 뒤집힌 동상 이후 조건부 구간을 구분했습니다.
- 왕을 기다리는 예배당의 고리의 포즈는 예약 구매·온라인 협력 조건을 보존해 보류합니다. 사종루 전송문 설명에 나오는 목적지 보상을 전송문 위치의 loot로 복제하지 않습니다.
- `LSDL-1908`은 원본이 **Z축 겹침 회피를 위해 실제 위치에서 옆으로 옮겼다**고 명시합니다. 원본 좌표를 유지하며 정확한 개별 획득 좌표라고 보장하지 않습니다.
- 색 잃은 단석인데 코드가 일반단석인 `LSDL-1411`, 기존 스톰빌의 `2350` 등은 원본 분류와 이름을 보존합니다. 성관의 타깃 실드/타워 실드 표기 차이도 기존 보류를 유지합니다.
- `LSDL-1596` 암월의 반지 설명은 선행 아이템의 연결 문구가 중복돼 있습니다. `LSDL-2419`의 중량 30% 접근 설명 등도 인게임으로 확인하지 않았으며 임의로 교정하지 않았습니다.
- 원본이 빛바랜 자 팩 조건을 붙인 `LSDL-3016`, `3017`은 제목과 위치를 보존하되 일반 본편 아이템임을 확인한 것으로 취급하지 않습니다. 조건 없는 획득 목록에는 추가하지 않았습니다.
- 이 데이터는 원본의 범위 내 정보를 정리한 것이며 모든 게임 아이템·좌표·수량의 인게임 전수 검증을 뜻하지 않습니다. DB·운영 데이터·마커 UI는 변경하지 않습니다.

## 검증 결과

- 이미지 범위 후보·원본·검토·생성 결과의 ID 집합 369개가 일치하며 좌표가 `0~1` 안에 있습니다. 스톰빌과 겹치는 원본의 이름·좌표·코드·설명이 이전 스냅샷과 동일한 것도 확인했습니다.
- 기존 림그레이브 232개·반도 125개·스톰빌 140개의 ID·좌표·분류·이름·획득 목록을 작업 전 객체 전체와 비교해 변경 없음을 확인했습니다. 기존 두 생성 대상의 `--check`도 통과했습니다.
- PC 기본 뷰포트와 모바일 `390×844`에서 해파리의 방패, 결정 갱도의 아이템·수량, 레날라의 두 처치 보상, 학원 정문 앞 묘지 룬 수량, 개종된 탑의 메모리 스톤을 확인했습니다.
- 같은 위치의 동부 대지 축복 세 개 중 첫 번째와 세 번째를 키보드로 독립 선택했습니다. 전체 보기에서는 겹침 때문에 개별 클릭이 어려운 기존 UI 한계가 있습니다.
- 모바일 최대 8배 확대·학원 쪽 드래그 이동·레날라 마커 직접 클릭·목록 닫기·전체 보기 복귀를 확인했습니다. 기본 PC 화면에 마커 369개가 렌더링됐고 선택 해제 후 선택 수 0개, 가로 넘침·브라우저 오류 로그 없음도 확인했습니다.
- lint·typecheck·변경 파일 포맷·diff 검사와 재생성 대조를 통과했습니다. 실제 Android Chrome·iOS Safari 기기 검증은 하지 않았습니다. 빌드 설정·라우트 구조·서버와 클라이언트 경계는 변경하지 않았습니다.
