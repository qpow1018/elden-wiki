# 도읍 로데일 지도 수집 기록

지역 ID `14`, 개발 모드 `/maps/14`용 데이터입니다. [수집 기준](../../../docs/MAP_DATA_IMPORT.md)을 따릅니다. 로데일 외곽 ID `13`은 다음 작업이며 이번에 수정하지 않습니다. 먼저 전체 원본과 지하·재의 도읍 혼합 설명을 검토해 외곽에서 재사용할 기준을 마련했습니다.

## 출처와 재생성

- [LSDL 본편 공개 지도](https://edring.lsdl.kr/map)와 [분류 스크립트](https://edring.lsdl.kr/assets/js/map.js), 확인일 `2026-11-21`. 적용 게임 버전은 미확인입니다.
- `source.json`: 이미지 범위의 64개 원본 번호·제목·좌표·코드·설명, 전체 2,096개 좌표 인덱스, 분류·이미지 해시·변환·정합 지표입니다.
- `review.json`: 64개 설명의 검토, 획득 목록·수량·보류 이유, 검토용 소속 `contentScopes`와 분리 보류한 `deferredLoot`입니다. 알터 고원과 겹치는 4개는 원본 필드 전체가 같은지 확인하고 기존 검토·목록 순서를 재사용했습니다.
- 생성기는 원본·검토·생성 결과의 ID 집합과 저장된 자료의 일치를 확인합니다. 이후 사이트 변경이나 사람의 해석 정확성은 자동 검증 대상이 아닙니다.

```bash
node reference-data/maps/generate.mjs leyndell-royal-capital
node reference-data/maps/generate.mjs leyndell-royal-capital --check
```

## 지형과 좌표

- 이미지 `src/assets/images/maps/14_leyndell_royal_capital.webp`, `2400×2100`입니다. SHA-256과 변환 행렬은 원본 기록에 있습니다. 초기 도읍 지상 이미지이며 별도 지하 평면도나 재의 도읍 배경이 아닙니다.
- 원본은 `L.CRS.Simple`, 줌 5·타일 256px입니다. `https://edring.lsdl.kr/assets/maptiles/5/tile_{x}_{y}.jpg`의 x `13..17`, y `10..14`를 사용합니다.
- `u = sourceX × 32 - 3328`, `v = -sourceY × 32 - 2560`을 행렬에 넣고 가로 2400·세로 2100으로 나눕니다. 최종 값만 소수점 여섯 자리로 반올림하며 경계로 잘라 넣지 않습니다.
- SIFT 최대 16,000개, 대상 40% 축소, BFMatcher 비율 0.65, affine RANSAC 4px로 추정했습니다. 최초 3,082개 대응 후보 중 3,053개 채택, 잔차 중앙값 0.50px·95백분위 1.76px입니다.
- 별도 특징점 추출·시드 20의 20% 분리 검증은 607개 중 603개가 5px 이내, 전체 중앙값 0.46px·95백분위 2.07px였습니다. 4개는 큰 불일치점이므로 모든 대응점이 정확한 것은 아닙니다.
- 검증점은 3×3 모든 구역에 분포하며 각 구역의 95백분위는 약 1.53~3.03px입니다. 서쪽 성관·북쪽 성벽·동쪽 건물·남쪽 황금 나무의 지형 확대 대조도 확인했습니다. 배경 정합과 개별 원본 마커의 층별 정확도는 별개입니다.

## 소속·진행 시점의 검토

LSDL에는 층·진행 단계 필드가 없습니다. 아래는 제목·설명과 연결 관계를 사람이 검토한 소속이며, 모든 물품의 전체 진행 단계별 존속 여부를 확정한 표가 아닙니다.

| contentScopes     | 개수 | 의미                                |
| ----------------- | ---: | ----------------------------------- |
| royal-capital     |   46 | 도읍 지상과 관련 마커               |
| underground       |    9 | 지하 축복·대표점·던전·봉인·NPC      |
| ashen-capital     |    7 | 후반 전용 4개와 초기/후반 혼합 3개  |
| capital-outskirts |    4 | 이미지에 보이는 외곽 묘지·진입부 등 |
| erdtree-interior  |    1 | 최종 보스·엔딩 대표점               |

혼합 마커는 양쪽에 속하므로 개수 합은 64개가 아닙니다. 이번 생성 데이터와 UI는 `contentScopes`·`deferredLoot`를 사용하지 않습니다. 화면에는 후보 64개를 모두 표시하며 층·시점 필터는 추가하지 않았습니다. 지하 ID `18`, 재의 도읍 ID `26`에는 아직 데이터를 연결하지 않았습니다.

- 여왕의 규방 `530`: 황금 나무의 은혜만 현재 목록에 연결하고 말리케스 이후 황금 나무의 회복은 재의 도읍 항목으로 분리 보류합니다.
- 첫 왕 고드프리 `1651`: 부적 주머니만 연결하고 같은 원본 설명의 기드온·온지혜의 왕홀은 재의 도읍으로 분리 보류합니다.
- 모르고트 `2442`: 거대한 룬·추억만 연결하고 호라 루의 추억은 재의 도읍으로 분리 보류합니다. 두 추억의 교환품·룬 환산은 현장 보상이 아닙니다.
- `2955` 고룡의 색 잃은 단석·`2980` 은총 +2: 원본에 말리케스 처치 후 등장이라고 명시되어 있습니다. 별도 제목·좌표가 있는 원본 마커와 목록은 유지하고 재의 도읍 소속을 기록했습니다. 현재 화면에는 이 등장 조건이 표시되지 않습니다.
- 금가면·콜린 최종 `2969`, `2970`: 재의 도읍 퀘스트 보상을 조건부 목록으로 보존합니다. 다른 위치 `2968`의 빛나는 금 가면 링크는 복제하지 않습니다.
- `1689` 성스러운 숫돌 칼날: 원본의 재의 도읍에서 획득 불가 조건을 보존합니다. 재의 도읍 아이템으로 복제하지 않습니다.

## 획득 목록과 누락 대조

- 후보 64개 전부 반영, 제외·중복 ID 없음. 미분류 4개와 원본 제목 스포일러도 ID를 보존합니다. 같은 이름의 축복·던전과 근접한 그림 `2610`·`2612`를 임의로 합치지 않습니다.
- 설명 64개를 검토해 34개 마커에 획득 항목 85건을 연결했습니다. 개별 물품 종류 수나 지역 총 획득 수량을 뜻하지 않습니다. 원본 전체와 보류 정보가 남아 있으며 게임의 모든 아이템이 수집됐다는 보장은 아닙니다.
- 지하 대표점 `1128`: 내부와 모그의 처치·상자 보상을 28개 항목으로 연결합니다. 단석 [7] 11개, 색단석 [6]·[7] 각각 2개, 룬의 호 2개 등 명시 수량을 유지합니다. 스카라베 1은 전체 수량 안의 경로 정보이므로 더하지 않습니다.
- 지하 묘지 `1806`은 묘 은방울꽃 [8] 4개·[9] 2개, 영혼묘 [8] 1개, 성혈 싹 2개와 탈리스만을 대표점에 연결합니다. 피 개 2마리는 획득 수량이 아닙니다.
- 미친 불의 봉인 `1810`은 현장 아이템 10개 항목을 연결합니다. 제작서의 미친 불의 돌은 해금 제작법, 엔딩 분기 후의 미친불의 성인은 조건부 보상으로 분리합니다. `525`의 지문석 방패 안내 링크는 봉인 목록에 이미 있어 축복에 복제하지 않습니다.
- 아우리자 영웅 묘지의 세트는 구성 부위가 원문에 없으므로 세트 단위로 유지합니다. 기도서는 물품만 연결하고 전달 후 배우는 기도는 제외합니다.
- 대변 먹는 자의 살해·정약·저주 전달, 베르나르 암살 의뢰, 금가면·콜린, 팩 조건 장비는 원문과 `deferredLoot`에 보존합니다. 정약 꼭두각시의 다른 장소 획득 경로를 지하 현장 지급으로 확정하지 않습니다.
- `deferredLoot`는 현 목록에서 빠진 조건부·혼합 시점 항목의 추적 자료입니다. 교환품·해금·다른 위치의 참조는 원문과 사유로 별도 보존하며 모두 보류 항목에 중복 등록하지 않습니다.
- 그림 날지 못하는 새의 불의 대죄는 다른 지역 보상 위치 `2611`이므로 여기 복제하지 않습니다. 황금 지네의 초 랜덤 드롭도 확정 목록에서 제외합니다.
- 개별 상자·시체·지하 통로의 층별 좌표를 추정하지 않습니다. 다음 외곽 작업도 독립적으로 전체 후보를 수집한 뒤 이 원본 ID와 검토를 재사용해야 합니다. 기존에 처리했다는 이유로 외곽 후보를 제외하지 않습니다.

## 검증

- 후보·원본·검토·생성 결과 ID 집합과 좌표를 대조했습니다. 기존 열한 지역 배열 전체가 Git HEAD와 동일하고 이전 생성 대상들의 재생성 대조도 통과했습니다.
- 소속 64개 전부 기록, 혼합 마커 3개의 후반 보상 분리, 지하 목록·명시 수량, 조건부 보류 목록을 검사했습니다.
- PC 기본 화면에서 고드프리는 부적 주머니만, 모르고트는 거대한 룬·추억만 표시하는지 확인했습니다. 모바일 390×844에서 지하 대표점 28개 항목·수량, 황금률 원론의 물품만 표시, 규방의 초기 기도만 표시를 확인했습니다.
- 모바일 최대 8배 금 간 항아리 직접 클릭·목록, 드래그·닫기·전체 보기 복귀를 확인했습니다. 전체 보기 64개 렌더링, 선택 해제 0개, 가로 넘침과 브라우저 오류 로그 없음도 확인했습니다. 실제 Android/iOS 기기는 미확인입니다.
- lint·typecheck·변경 파일 포맷·diff·재생성 대조를 통과했습니다. UI·DB·운영 데이터와 라우트·빌드 설정·서버/클라이언트 경계는 변경하지 않았습니다.
