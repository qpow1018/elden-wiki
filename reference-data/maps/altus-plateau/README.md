## 지형과 좌표 정합

- 이미지 `src/assets/images/maps/11_altus_plateau.webp`, `6000×4770`. SHA-256과 변환 행렬은 원본 기록에 있습니다. 별도 삽입 영역 없이 하나의 연속된 지형입니다.
- 원본은 `L.CRS.Simple`, 줌 5·타일 256px입니다. `https://edring.lsdl.kr/assets/maptiles/5/tile_{x}_{y}.jpg`의 x `6..14`, y `6..14`를 사용합니다.
- `u = sourceX × 32 - 1536`, `v = -sourceY × 32 - 1536`을 행렬에 넣고 가로 6000·세로 4770으로 나눕니다. 최종 값만 소수점 여섯 자리로 반올림하며 경계로 잘라 넣지 않습니다.
- SIFT 최대 16,000개, 대상 이미지 40% 축소, BFMatcher 비율 0.65, affine RANSAC 4px로 추정했습니다. 최초 3,871개 대응 후보 중 3,822개를 채택했고 잔차 중앙값 0.40px·95백분위 1.39px입니다.
- 별도 특징점 추출·시드 20의 20% 분리 검증에서는 768개 중 758개가 5px 이내, 전체 중앙값 0.42px·95백분위 1.64px였습니다. 큰 불일치점 10개가 있어 모든 대응점이 맞았다는 뜻은 아닙니다.
- 검증점은 3×3 모든 구역에 분포합니다. 북동쪽 구역은 이상치 때문에 전체 95백분위가 약 559px이며, 다른 구역은 약 1.36~1.76px입니다. 서쪽 화산관 용암·북쪽 그늘성·동쪽 성벽·남쪽 지형의 원본/대상 확대 대조도 별도로 확인했습니다.
- 이는 배경 지형 정합이며 개별 LSDL 마커의 실제 게임 배치·층을 전수 검증한 것은 아닙니다. 원본 타일 확대 흐림과 대표점 오차는 남습니다.
