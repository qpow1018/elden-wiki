# 로데일 외곽 지도 수집 기록

지역 ID `13`, 개발 모드 `/maps/13`용 데이터입니다. [수집 기준](../../../docs/MAP_DATA_IMPORT.md)을 따릅니다. 도읍 로데일을 먼저 검토한 뒤 외곽을 독립 수집했습니다. 이미지에 도읍 내부도 보이므로 원본 번호가 겹쳐도 제외하지 않습니다.

## 출처와 재생성

- [LSDL 본편 공개 지도](https://edring.lsdl.kr/map)와 [분류 스크립트](https://edring.lsdl.kr/assets/js/map.js), 확인일 `2026-11-21`. 적용 게임 버전은 미확인입니다.
- `source.json`: 범위 내 118개 원본 번호·제목·좌표·코드·설명, 전체 2,096개 좌표 인덱스, 분류·이미지 해시·변환·검증 지표입니다.
- `review.json`: 118개 설명의 검토·획득 목록·수량·보류 이유입니다. 알터 고원 44개·도읍 63개와 겹치며 양쪽에 공통인 4개를 빼면 재사용 원본은 103개입니다. 모든 필드를 비교해 같은 원본인지 확인하고 기존 검토·항목 순서·소속·보류 목록을 그대로 재사용했습니다. 신규 원본은 15개입니다.
- 공통 생성기로 저장 자료와 생성 결과를 대조합니다. 이후 사이트 변경이나 사람의 해석 정확성은 자동 검증 대상이 아닙니다.

```bash
node reference-data/maps/generate.mjs leyndell-outskirts
node reference-data/maps/generate.mjs leyndell-outskirts --check
```

## 지형과 좌표

- 이미지 `src/assets/images/maps/13_leyndell_outskirts.webp`, `3600×3300`입니다. SHA-256과 변환 행렬은 원본 기록에 있습니다. 별도 삽입 영역 없는 연속된 지상 지도입니다.
- 원본은 `L.CRS.Simple`, 줌 5·타일 256px입니다. `https://edring.lsdl.kr/assets/maptiles/5/tile_{x}_{y}.jpg`의 x `11..17`, y `8..14`를 사용합니다.
- `u = sourceX × 32 - 2816`, `v = -sourceY × 32 - 2048`을 행렬에 넣고 가로 3600·세로 3300으로 나눕니다. 최종 값만 소수점 여섯 자리로 반올림하며 경계로 잘라 넣지 않습니다.
- SIFT 최대 16,000개, 대상 이미지 40% 축소, BFMatcher 비율 0.65, affine RANSAC 4px로 추정했습니다. 최초 4,092개 대응 후보 중 4,066개를 채택했고 잔차 중앙값 0.45px·95백분위 1.51px입니다.
- 별도 특징점 추출·시드 20의 20% 분리 검증에서는 808개 중 806개가 5px 이내, 전체 중앙값 0.44px·95백분위 1.52px였습니다. 2개는 큰 불일치점이므로 모든 대응점이 정확한 것은 아닙니다.
- 검증점은 3×3 모든 구역에 있고 각 구역의 95백분위는 약 1.18~2.68px입니다. 서쪽 대교·북쪽 성벽·동쪽 진입부·남쪽 도읍 건물 지형 확대도 대조했습니다. 배경 정합과 개별 마커의 실제 위치·층은 별개입니다.

## 누락·중복 대조와 획득 정보

- 최종 외곽 후보 118개를 전부 반영합니다. 제외·중복 ID 없음, 원본 필터가 없는 24개도 유지합니다. 무명 마커는 없습니다.
- 도읍 64개와 외곽 118개의 교집합은 63개, 합집합은 119개입니다. 도읍에만 있는 `LSDL-2447` 최종 보스 대표점은 외곽 이미지 밖이라 외곽에 넣지 않았습니다. 외곽만의 원본 55개 중 40개는 알터 고원 검토와 겹치고 15개는 신규입니다.
- 도읍에서 처리했다는 이유로 외곽 후보를 제외하지 않았습니다. 같은 원본 ID는 각각의 이미지 변환으로 표시하며 동일 이미지 안에 중복 생성하지 않습니다.
- 설명 118개를 검토해 77개 마커에 획득 항목 155건을 연결했습니다. 이는 아이템 종류 수나 지역 총 획득 수량이 아닙니다.
- 신규 `1071` 용의 트리가드는 대룡조·용 발톱의 방패, `1604` 외곽 침입은 미에로스의 검, `1807` 야간 죽음의 새는 쌍조의 카이트 실드를 연결합니다. 지하 NPC의 다른 분기 보상을 외곽 침입 보상으로 복제하지 않습니다.
- 아우리자 부묘지 `1633`은 금 간 항아리·의식 항아리 2개·조향사의 제작서 [3]·특공대의 뼛가루를 연결합니다. 철 항아리 영약은 제작법 해금입니다. 원문에 금 간 항아리 4개와 시작 유품 선택 시 2개 부재가 함께 있어, 일반 목록에서는 수량을 확정하지 않고 원문·검토 이유에 두 조건을 남깁니다. 원본 주장의 인게임 검증은 하지 않았습니다.
- 북쪽 작은 황금 나무 `2547`은 가는 가지 깨진 물방울·붉은 결정 물방울을 연결합니다. `1808` 날개 결정 물방울의 3분·4.5배와 다른 물방울의 비율도 획득 수량이 아닙니다.
- 불량배 `1605`는 새우·게 판매와 가격·효과, 대변 먹는 자 이벤트 사망 보상을 분리합니다. 모판의 저주·방울·철구권·철 가면은 조건부 보류 목록에 보존합니다. 부여된 과시하는 포효를 별도 전회 획득품으로 중복 등록하지 않습니다.
- 트라고스 `2548`의 소환 제스처와 팩 조건 영마 복장 `3014`도 원문·보류 목록에 남깁니다. 일반 본편 여부 미확인 자료를 확정 획득품으로 넣지 않습니다.
- 도읍에서 분리한 혼합 시점과 지하 정보는 [도읍 기록](../leyndell-royal-capital/README.md)·검토 자료를 그대로 유지합니다. 현재 UI에는 범위 내 지상·지하·재의 도읍 마커가 함께 표시되며 층·시점 필터는 아직 없습니다. 지하 ID `18`, 재의 도읍 ID `26`도 변경하지 않습니다.
- 개별 시체·상자·통로의 층별 좌표를 추정하지 않습니다. LSDL 스냅샷의 범위 내 보존을 검증한 것이며 게임의 모든 아이템·수량·조건을 검증한 자료는 아닙니다.

## 검증

- 후보·원본·검토·생성 결과 ID 집합과 전 좌표를 대조했습니다. 도읍/외곽의 합집합·교집합과 재사용 검토 전체도 비교했습니다.
- 작업 시작 시점의 도읍 미커밋 데이터와 기존 열한 지역 배열을 포함한 열두 지역이 그대로 유지됐습니다. 이전 생성 대상들의 재생성 대조도 통과했습니다.
- PC 기본 화면에서 용의 트리가드의 두 보상, 아우리자 부묘지의 네 항목·수량을 확인했습니다. 모바일 390×844에서 북쪽 나무의 두 물방울과 불량배 조건부 목록 미표시를 확인했습니다.
- 모바일 최대 8배 드래그로 해자 이동·대변 먹는 자 침입 마커 직접 클릭·미에로스의 검 목록, 닫기·전체 보기 복귀를 확인했습니다. 전체 보기 118개 렌더링, 선택 해제 0개, 가로 넘침과 브라우저 오류 로그 없음도 확인했습니다. 실제 Android/iOS 기기는 미확인입니다.
- lint·typecheck·변경 파일 포맷·diff·재생성 대조를 통과했습니다. UI·DB·운영 데이터와 라우트·빌드 설정·서버/클라이언트 경계는 변경하지 않았습니다.
