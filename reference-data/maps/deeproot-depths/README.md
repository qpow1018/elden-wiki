# 깊은 뿌리 밑바닥 지도 수집 기록

지역 ID `10`, 개발 모드 `/maps/10`용 데이터입니다. [수집 기준](../../../docs/MAP_DATA_IMPORT.md)을 따릅니다. 합성 이미지의 본 지도와 우상단 카리아의 서원·리에니에 신수탑 삽입 영역을 각각 정합했습니다. 삽입 범위에 보이는 항아리 마을과 주변 필드도 포함합니다.

## 출처와 재생성

- [LSDL 공개 본편 지도](https://edring.lsdl.kr/map)와 [분류 스크립트](https://edring.lsdl.kr/assets/js/map.js), 확인일 `2026-11-21`. 적용 게임 버전은 미확인입니다.
- `source.json`: 본 지도 59개·삽입 지도 19개, 총 78개 원본 번호·제목·좌표·코드·설명, 전체 2,096개 좌표 인덱스, 분류·이미지 해시·영역별 변환과 검증 지표입니다.
- `review.json`: 78개 설명의 검토·획득 목록·보류 이유입니다. 기존 리에니에 동·서부와 겹치는 17개 원본의 모든 필드를 비교해 같음을 확인하고 기존 검토·항목 순서를 재사용했습니다.
- 공통 생성기는 `panels`가 있는 경우 각 영역의 원점·변환·표시 범위·가림 범위를 사용하고, 기존 자료는 기존 단일 변환을 사용합니다. 한 원본이 두 영역에 동시에 속하면 중단합니다. 저장 자료와 생성 결과를 검증하며 이후 사이트 변경·해석 정확성은 자동 검증하지 않습니다.

```bash
node reference-data/maps/generate.mjs deeproot-depths
node reference-data/maps/generate.mjs deeproot-depths --check
```

## 합성 이미지 좌표 정합

- 이미지 `src/assets/images/maps/10_deeproot_depths.webp`, `4500×2700`. SHA-256과 두 변환 행렬은 원본 기록에 있습니다.
- 원본은 `L.CRS.Simple`, 줌 5·타일 256px입니다. URL은 `https://edring.lsdl.kr/assets/maptiles/5/tile_{x}_{y}.jpg`입니다.
- 본 지도: 타일 x `7..11`, y `1..5`, 원점 `(1792,256)`. `u = sourceX × 32 - 1792`, `v = -sourceY × 32 - 256`을 본 지도 행렬에 넣습니다.
- 삽입 지도: 타일 x `9..13`, y `16..19`, 원점 `(2304,4096)`. `u = sourceX × 32 - 2304`, `v = -sourceY × 32 - 4096`을 삽입 행렬에 넣습니다.
- 삽입 표시 사각형은 원본 이미지 픽셀 `[2350,120,4450,1060]`입니다. 본 지도에서는 이 사각형을 가림 영역으로 제외합니다. 각 결과를 가로 4500·세로 2700으로 나누고 최종 값만 소수점 여섯 자리로 반올림합니다. 범위 밖 좌표는 경계로 잘라 넣지 않습니다.
- SIFT 최대 16,000개, 대상 40% 축소, BFMatcher 비율 0.65, affine RANSAC 4px로 각각 추정했습니다. 본 지도는 최초 3,680개 중 3,657개 채택, 잔차 중앙값 0.62px·95백분위 1.88px입니다. 삽입은 1,181개 중 1,162개, 중앙값 0.52px·95백분위 1.71px입니다.
- 별도 특징점 추출·시드 20의 20% 분리 검증에서 본 지도 730개 중 725개가 5px 이내, 전체 중앙값 0.62px·95백분위 1.99px였습니다. 삽입은 233개 중 231개, 중앙값 0.56px·95백분위 2.15px입니다. 각각 5개·2개의 큰 불일치점이 남아 모든 대응점이 정확한 것은 아닙니다.
- 검증점은 본 지도의 서쪽·중앙과 북쪽/남쪽에 분포합니다. 전체 이미지 오른쪽 세로 1/3은 본 지형이 없는 영역이므로 본 지도 검증점이 없습니다. 삽입 검증점은 그 영역 자체에 분포합니다. 서쪽 폐허·동쪽 뿌리·남쪽 지형·삽입 교량 확대 대조도 확인했습니다.
- 지형 정합과 개별 마커의 실제 게임 배치·층 정확도는 별개입니다. 원본 타일 해상도에 따른 흐림은 남습니다.

## 획득 정보와 한계

- 최종 범위 후보 78개 전부 반영, 제외·중복 ID 없음. 원본 필터가 없는 8개도 유지합니다. 같은 이름의 장소·축복·개별 물품은 원본 번호로 구분합니다.
- 설명 78개를 검토해 56개 마커에 획득 항목 67건을 연결합니다. 미기재 수량을 1로 추정하지 않습니다.
- 실루리아의 나무창·피아의 안개·엘데의 유성·죽음의 왕자의 지팡이 등 현장 획득품을 연결합니다. 포르삭스는 사룡의 추억만 연결하며 룬 환산과 교환 기도는 제외합니다.
- 리에니에 신수탑 `272`에는 죽음의 주흔·별 보는 소녀의 전승을 연결합니다. 서원 `1475`은 기존 동·서부처럼 처음 접근 가능한 세 아이템만 연결하고 뒤집힌 동상 조건의 후반 목록은 보류합니다. 교량 귀인의 방어구·항아리 마을 대표점의 명시 수량도 유지합니다.
- 피아 `2138`과 D `2139`의 다단계 조건부 보상은 원문·보류 이유에 보존합니다. 디아로스·작은 항아리의 퀘스트 보상, 기도서·방울의 해금 상품과 반복 파밍도 기존 검토 기준대로 일반 획득 목록에서 분리합니다.
- `2150`은 영혼 묘 은방울꽃 [7] 제목이지만 색단석 코드입니다. 분류를 임의로 고치지 않고 원본을 유지합니다. `2151`은 도가니의 기사 세트라는 제목만 있어 구성 부위를 추정하지 않습니다.
- 접근 조건·루트·높이 차이는 원문·검토에 남지만 현재 목록 UI에서 직접 표시하지 않습니다. 인게임 모든 개별 물품·수량·층을 검증한 자료는 아닙니다.
