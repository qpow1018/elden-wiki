# 케일리드 지도 수집 기록

지역 ID `8`, 개발 모드 `/maps/8`용 데이터입니다. [수집 기준](../../../docs/MAP_DATA_IMPORT.md)을 따릅니다. 케일리드·용총·적사자성과 이미지 왼쪽에 보이는 림그레이브 일부를 포함합니다. 이미지 밖인 짐승의 신전 등 북쪽 전체 수집을 뜻하지 않습니다.

## 출처와 재생성

- [LSDL 본편 지도](https://edring.lsdl.kr/map)와 [분류 스크립트](https://edring.lsdl.kr/assets/js/map.js), 확인일 `2026-11-21`. 게임 적용 버전은 미확인입니다.
- `source.json`: 범위 내 199개 원본 번호·제목·좌표·코드·설명, 전체 2,096개 좌표 인덱스와 분류·이미지 해시·변환·정합 지표입니다. 계정 정보는 보관하지 않습니다.
- `review.json`: 모든 설명의 검토와 획득 목록·수량·보류 이유, 기존 림그레이브와 겹치는 26개 원본 ID입니다. 다른 지역의 데이터는 변경하지 않습니다.
- 공통 생성기로 저장된 자료와 생성 결과를 대조합니다. 이후 사이트 변경과 사람의 해석 정확성은 자동 검증 대상이 아닙니다.

```bash
node reference-data/maps/generate.mjs caelid
node reference-data/maps/generate.mjs caelid --check
```

## 지형 정합

- 대상 `src/assets/images/maps/8_caelid.webp`, `6300×5340`. SHA-256과 변환 행렬은 원본 기록에 보관합니다.
- 원본 `L.CRS.Simple`, 줌 5·타일 256px. `https://edring.lsdl.kr/assets/maptiles/5/tile_{x}_{y}.jpg`의 x `14..21`, y `18..26`을 사용합니다.
- `u = sourceX × 32 - 3584`, `v = -sourceY × 32 - 4608`를 행렬에 넣고 가로 6300·세로 5340으로 나눕니다. 최종 값만 소수점 여섯 자리로 반올림하고 경계로 잘라 넣지 않습니다.
- SIFT 최대 16,000개, 대상 이미지 40% 축소, BFMatcher 비율 0.65, affine RANSAC 4px로 추정했습니다. 최초 4,012개 대응 후보 중 3,753개를 채택했고 잔차 중앙값 0.47px·95백분위 1.52px입니다.
- 별도 특징점 추출·시드 20의 20% 분리 검증에서 789개 중 781개가 5px 이내였습니다. 전체 중앙값 0.49px·95백분위 1.65px입니다. 큰 불일치점 8개가 있어 모든 후보가 맞았다는 뜻은 아닙니다.
- 검증점은 3×3 모든 구역에 분포합니다. 북동쪽 구역은 큰 불일치점 때문에 전체 95백분위가 약 5,156px이며, 다른 구역은 약 1.28~2.03px입니다. 서쪽 길·북동쪽 절벽·적사자성 건물의 원본/대상 지형 확대 대조도 별도로 확인했습니다.
- 배경 지형 정합과 개별 마커의 실제 게임 배치는 별개입니다. 최대 확대 시 원본 타일의 해상도·개별 대표점 오차가 남을 수 있습니다.

- 최종 후보 199개 전부 반영, 제외·중복 ID 없음. 원본 필터가 없는 35개와 제목이 없는 `935`, `1031`, `2918`, `2919`도 보존합니다. 이름이 같은 축복·장소·보스는 원본 ID로 구분합니다.
