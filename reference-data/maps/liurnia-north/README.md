# 리에니에 북부 지도 수집 기록

지역 ID `5`, 개발 모드 `/maps/5`용 데이터입니다. [지도 데이터 수집 기준](../../../docs/MAP_DATA_IMPORT.md)을 따릅니다. 카리아 성관·세 자매·덱타스 대승강기와 이미지 안에 보이는 알터 고원 일부, 남쪽 테스의 마술사탑·미친 불 마을 등을 이미지 범위 기준으로 수집합니다.

## 출처와 재생성

- [LSDL 본편 지도](https://edring.lsdl.kr/map), 확인일 `2026-11-20`. 공개 HTML의 `gmarkers`와 `map.js`를 새로 읽었습니다. 원본 적용 게임 버전은 미확인입니다.
- `source.json`에는 이미지 범위의 마커 138개의 원본 번호·제목·좌표·코드·설명, 전체 2,096개 좌표 인덱스와 코드 분류, 이미지 해시·해상도·좌표 변환·정합 지표를 보존합니다. 계정 정보는 저장하지 않습니다.
- `review.json`에는 138개 설명의 검토 결과, 획득 목록·수량과 보류 이유, 기존 지역과의 원본 ID 중복을 기록합니다. 동·서부와 겹치는 38개 원본은 이름·좌표·분류 코드·설명이 기존 스냅샷과 같은지 확인하고 검토 기준을 유지했습니다.
- 공통 `../generate.mjs`를 사용합니다. 저장된 스냅샷·검토와 생성 결과의 일치를 확인하며, 이후 사이트 변경이나 사람의 해석 정확성까지 자동 검증하지 않습니다.

저장소 루트에서 실행합니다.

```bash
node reference-data/maps/generate.mjs liurnia-north
node reference-data/maps/generate.mjs liurnia-north --check
```

## 지형과 좌표 정합

- 대상 이미지: `src/assets/images/maps/5_liurnia_north.webp`, `4590×2850`. SHA-256은 `source.json`에 보존합니다.
- 원본 타일: `https://edring.lsdl.kr/assets/maptiles/5/tile_{x}_{y}.jpg`, x `4..11`, y `9..15`, 타일 `256×256`. 모자이크 원점 `(1024, 2304)`입니다.
- `u = sourceX × 32 - 1024`, `v = -sourceY × 32 - 2304`를 원본 기록의 2×3 변환 행렬에 넣고, 결과를 가로 4590·세로 2850으로 나눕니다. 최종 값만 소수점 여섯 자리로 반올림하며 이미지 밖 좌표를 경계로 잘라 넣지 않습니다.
- SIFT 특징점 최대 16,000개, 대상 이미지 40% 축소, BFMatcher 2근접 비율 0.65, RANSAC 기준 4px의 `estimateAffine2D`로 정합했습니다. 최초 후보 3,391개 중 3,130개를 채택했고 잔차 중앙값 약 0.43px·95백분위 약 1.46px입니다.
- 별도 특징점 재추출 후 난수 시드 20으로 20%를 분리하고 나머지로 변환을 추정했습니다. 후보 3,388개의 분리 표본 677개 중 668개가 5px 이내입니다. 전체 중앙값 약 0.46px·95백분위 약 1.75px, 5px 안의 점만 보면 95백분위 약 1.48px입니다. 나머지 9개는 큰 불일치점이므로 모든 대응점이 정확히 맞았다고 해석하지 않습니다.
- 분리 표본은 3×3 모든 구역에 분포합니다. 남동쪽 구역에는 큰 불일치점도 있어 해당 구역의 전체 95백분위는 작지 않습니다. 성관 건물·대승강기 주변 가도·진정의 교회·남동쪽 황금 나무의 원본/대상 지형 확대 비교를 별도로 확인했습니다.
- 이는 배경 지형 정합 확인이며 LSDL 개별 마커의 실제 게임 배치·층을 전수 확인한 것은 아닙니다.

## 반영 범위와 해석

- 최종 이미지 범위 후보 138개를 모두 반영합니다. 제외 0개·중복 ID 0개이며 후보 좌표 인덱스·원본·설명 검토·생성 결과의 ID 집합을 비교합니다.
- 계곡에 숨은 마을 `LSDL-612`, `613`과 진정의 교회 위치의 `2825`, `2826`은 같은 좌표여도 서로 다른 원본 번호를 유지합니다. `2825`는 제목이 없는 축복이며 임의로 합치거나 삭제하지 않습니다.
- 원본 제목이 없는 `LSDL-409`, `2825`는 표시명만 `이름 없는 마커`로 두고 번호·좌표를 유지합니다.
- 설명 138개를 검토해 55개 마커에 획득 목록 95건을 연결합니다. 명시된 수량을 가진 개별 물품도 포함하며 서로 다른 아이템 종류 수나 지역 총 획득 수량을 뜻하지 않습니다.
- 로레타의 대궁·로레타의 참격, 마카르의 토룡의 비늘검·용의 심장, 왕가 묘지 봉인감옥의 메테오라이트, 황금 일족 봉인감옥의 고드프리의 초상 등을 해당 원본 마커에 연결합니다.
- 카리아 성관 내부 아이템은 원본 개별 마커와 방·구간 목록을 유지합니다. 동굴·절벽 구간의 단석·룬·뱀신의 곡도는 대표점에 목록으로 묶고, 개별 시체·상자의 층별 좌표를 추정하지 않습니다.
- 밤과 불꽃의 검의 필요 능력치, 카리아의 찌르기 FP·지력, 뼛가루의 FP, 마술의 슬롯을 아이템 수량으로 바꾸지 않습니다. 이름의 `*8`, `*2` 등 명시된 획득 수량은 목록에서 물품명과 분리합니다.
- 그림 재탄 보상 마커에는 유년 학도의 모자·로브·물방울 유생을 연결합니다. 마커 이름이 그림의 보상 위치임을 표시하며 그림 습득이 선행하는 보상으로 해석합니다.

## 보류와 원본 한계

- 이지·피디·방랑 민족 상인의 판매품과 셀브스의 선택·정약·발견 조건에 따른 마술·꼭두각시 보상은 원문과 보류 이유에 보존합니다. 구매 재고나 가격을 일반 획득 수량으로 넣지 않습니다.
- 블라이드 최종 적대·트라고스 암살 의뢰·협력 소환 제스처는 조건부 보상으로 보류합니다. 패치에게 돌아가 얻는 용암 채찍의 촛대도 암살 위치의 획득품이 아닙니다.
- 이 지역의 아듀라는 HP 50% 이하에 도주하는 조우입니다. 동·서부 월광 제단의 처치 보상을 같은 이름이라는 이유로 복제하지 않습니다.
- 라니의 방 `LSDL-910`과 상인 `1421`의 설명에는 빛바랜 자 팩 조건 물품이 있습니다. 일반 본편 물품임을 확인하지 않았으므로 원본에만 보존하고 조건 없는 획득 목록에 추가하지 않습니다.
- 원본 코드가 일반단석인데 제목은 색 잃은 단석인 `LSDL-1411`은 동·서부와 마찬가지로 원본 분류·제목을 유지합니다. 다른 원본 표기 오류도 인게임 확인 없이 임의로 바꾸지 않습니다.
- 상층·하층·성벽·절벽 접근 조건과 원본 대표점의 위치 한계가 있습니다. 실제 게임의 모든 물품·수량·좌표를 검증한 자료는 아닙니다.
- 기존 네 지역 데이터·마커 UI·DB·운영 데이터는 변경하지 않습니다.

## 검증 결과

- 원본 좌표 인덱스에서 계산한 후보·원본·검토·생성 결과 ID 집합 138개가 일치하고 좌표가 `0~1` 범위에 있음을 확인했습니다. 기존 네 지역 객체 전체 비교와 이전 생성 대상들의 `--check`도 통과했습니다.
- PC 기본 뷰포트와 모바일 `390×844`에서 밤과 불꽃의 검, 로레타의 두 보상, 마카르의 비늘검·용의 심장, 성관 묘지의 룬 수량, 셀브스 탑의 메모리 스톤을 확인했습니다.
- 같은 위치의 계곡에 숨은 마을 두 마커를 키보드로 각각 선택했습니다. 전체 보기에서 겹쳐 개별 클릭이 어려운 기존 UI 한계는 유지됩니다.
- 모바일 최대 8배 확대·성관 쪽 드래그 이동·밤과 불꽃의 검과 로레타 마커 직접 클릭·닫기·전체 보기 복귀를 확인했습니다. 기본 PC 화면에 138개가 렌더링됐고 선택 해제 후 선택 0개, 가로 넘침과 브라우저 오류 로그 없음도 확인했습니다.
- lint·typecheck·변경 파일 포맷·diff 검사와 재생성 대조를 통과했습니다. 실제 Android Chrome·iOS Safari 기기는 검증하지 않았습니다. 라우트 구조·빌드 설정·서버와 클라이언트 경계는 변경하지 않았습니다.
