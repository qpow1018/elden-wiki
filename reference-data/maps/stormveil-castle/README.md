# 스톰빌 성 지도 수집 기록

지역 ID `3`, 개발 모드 `/maps/3`에 반영하는 데이터입니다. [지도 데이터 수집 기준](../../../docs/MAP_DATA_IMPORT.md)을 따릅니다. 배경은 성의 층별 평면도가 아니라 폭풍의 언덕과 림그레이브 신수탑까지 포함하는 이미지입니다. 이 이미지 범위의 마커를 수집하며 성 내부 마커만으로 제한하지 않습니다.

## 출처와 재생성

- [LSDL 본편 지도](https://edring.lsdl.kr/map), 확인일 `2026-11-20`, 원본 게임 버전 미확인. 같은 날 반도 수집에 사용한 공개 스냅샷을 재사용했습니다.
- `source.json`에는 이미지 범위의 원본 마커 140개와 설명, 전체 2,096개 좌표 인덱스, 코드 기반 필터 매핑, 이미지 해시와 변환식을 보존합니다. 설명 키워드 필터는 마커 자체의 분류에 합치지 않습니다.
- `review.json`에는 설명 140개의 검토 결과와 획득 목록·보류 이유를 보존합니다. 림그레이브와 겹치는 원본 ID 74개도 기록합니다. 이전 CSV 데이터는 이 지역에 없습니다.
- `../generate.mjs`는 지역별 원본·검토 파일로 마커를 생성합니다. 반도와 같은 도구를 사용하며 네트워크 요청 없이 이미지 해시·후보 ID·설명 검토·생성 결과를 대조합니다.

저장소 루트에서 실행합니다.

```bash
node reference-data/maps/generate.mjs stormveil-castle
node reference-data/maps/generate.mjs stormveil-castle --check
node reference-data/maps/generate.mjs weeping-peninsula --check
```

검증 명령은 저장한 원본과 코드의 일치를 확인하며, 사이트의 이후 변경이나 검토자의 해석 정확성까지 보장하지 않습니다.

## 지형 정합

- 대상: `src/assets/images/maps/3_stormveil_castle.webp`, `4350×2160`. SHA-256은 원본 기록에 보존합니다.
- 원본: `https://edring.lsdl.kr/assets/maptiles/5/tile_{x}_{y}.jpg`, x `9..14`, y `20..24`, 타일 크기 `256×256`. 모자이크 원점 `(2304, 5120)`입니다.
- `u = sourceX × 32 - 2304`, `v = -sourceY × 32 - 5120`을 변환 행렬에 넣고, 결과 픽셀을 가로 4350·세로 2160으로 나눕니다. 최종 값만 소수점 여섯 자리로 반올림합니다.
- SIFT 특징점 최대 16,000개, 대상 이미지 40% 축소, BFMatcher 2근접 비율 0.65로 지형을 매칭했습니다. 대상 점을 원래 해상도로 복원하고 RANSAC 기준 4px로 `estimateAffine2D`를 추정했습니다. 최초 후보 4,207개 중 4,190개 채택, 잔차 중앙값 약 0.46px·95백분위 약 1.62px입니다.
- 별도로 특징점을 재추출하고 난수 시드 20으로 20%를 분리해 나머지로 변환을 추정했습니다. 검증 후보 4,196개의 분리 표본 839개 중 836개가 5px 이내이며 중앙값 약 0.49px·95백분위 약 1.75px입니다. 분리 표본은 3×3 모든 구역에 분포합니다. 반복 추출의 대응점 수는 최초 정합과 다릅니다.
- 성 내부 건물·중앙 교량·동쪽 신수탑의 원본/대상 지형 확대 비교도 확인했습니다. LSDL 개별 획득물의 게임 내 위치·층을 직접 검증한 것은 아닙니다.

## 반영과 해석

- 최종 이미지 범위의 140개 마커 모두 반영, 제외 0개·중복 ID 0개입니다. 경계의 고인물 동굴과 인접 지역도 포함합니다.
- 설명 140개를 검토해 55개 마커에 획득 항목 107건을 연결했습니다. 원문에 수량이 있는 개별 마커의 목록도 포함하며, 서로 다른 아이템 종류 수나 지역 전체의 총 획득 수량을 의미하지 않습니다.
- 방·옥상·지하·이동 구간 마커는 원본 좌표에 목록을 붙입니다. 원본에 없는 층별 좌표를 만들지 않습니다. 개별 갈고리 발톱 마커와 구간 목록 등은 원본의 두 표현으로 유지하며 수량을 합산하지 않습니다.
- 접목의 고드릭은 **고드릭의 거대한 룬·접목의 추억**만 처치 획득 목록으로 넣었습니다. 추억 교환 선택지인 고드릭 왕의 도끼·접목된 비룡은 현 위치 획득품이 아닙니다. 신수탑의 거대한 룬 활성화 역시 신규 획득으로 중복 집계하지 않습니다.
- 신의 살갗의 기도서 방에는 성인·룬·기도서만 넣고, 기도서가 해금하는 흑염·흑염의 칼날은 제외했습니다. 제작서의 제작법과 숫돌 칼날의 효과 설명도 획득품과 구분합니다.
- 상점 판매·NPC 퀘스트·무작위 파밍·특전 조건은 원문과 보류 이유에 보존합니다. 림그레이브의 기존 목록 중 일부에 있던 조건부 보상도 이번 지역에서는 현재 수집 기준에 따라 보류했습니다. 기존 림그레이브 데이터는 수정하지 않았습니다.
- LSDL-2350은 제목이 색 잃은 단석 [2]인데 코드 7(일반단석)입니다. LSDL-2365의 성관의 타깃 실드와 LSDL-543 설명의 성관의 타워 실드는 원본 표기·좌표를 유지하고, 같은 아이템인지 보류했습니다.
- 번데기 방의 유품·심홍색 후드는 원문에 함께 나오는 목록입니다. 원문에 시점 조건이 없으므로 동시에 획득할 수 있다고 단정하지 않습니다.
- 원본 제목이 없는 네 마커는 원본 ID와 좌표를 유지하고 표시명만 `이름 없는 마커`로 두었습니다.
- DB·운영 데이터·마커 UI는 변경하지 않았습니다. 기존 반도 생성 도구는 두 지역에서 재사용하도록 상위 폴더로 옮겼습니다.

## 검증 결과

- 원본 좌표 인덱스에서 계산한 후보·설명 검토·앱 반영 ID 집합 140개가 일치합니다. 생성 결과 대조와 이미지 해시 검사를 통과했습니다.
- 림그레이브 232개와 반도 125개의 ID·좌표·분류·획득 목록이 작업 전과 동일한지 객체 전체를 비교했습니다. 반도의 생성 명령과 기록 경로만 갱신했습니다.
- PC 기본 뷰포트와 모바일 `390×844`에서 140개 마커 표시, 갈고리 발톱, 고드릭의 두 처치 보상, 기도서 방과 식당 옆 석검 열쇠 방 목록, 묘지 룬 수량을 확인했습니다.
- 모바일 8배 확대·성 쪽 드래그 이동·방 마커 클릭·목록 닫기·전체 보기 복귀를 확인했습니다. 전체 보기에서 겹치는 마커는 키보드 선택으로 확인했고, 확대 후에는 식당 옆 방을 직접 클릭했습니다. 기존 밀집 마커 UI의 한계는 유지됩니다.
- 가로 넘침과 브라우저 오류 로그가 없는 것을 확인했습니다. 실제 Android Chrome·iOS Safari 기기는 검증하지 않았습니다.
- lint·typecheck·변경 파일 포맷·diff 검사를 통과했습니다. 이번 변경은 데이터·생성 도구이며 빌드 설정이나 서버·클라이언트 경계는 변경하지 않았습니다.
