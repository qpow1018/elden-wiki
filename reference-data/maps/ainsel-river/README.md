# 에인세르 강 지도 수집 기록

지역 ID `6`, 개발 모드 `/maps/6`용 데이터입니다. [수집 기준](../../../docs/MAP_DATA_IMPORT.md)을 따릅니다. 이미지 안에 보이는 본류·녹스텔라 일부도 포함하며 본류 지역 ID `15`의 전체 수집을 뜻하지 않습니다.

## 출처와 재생성

- [LSDL 본편 공개 지도](https://edring.lsdl.kr/map)와 [분류 스크립트](https://edring.lsdl.kr/assets/js/map.js), 확인일 `2026-11-21`. 적용 게임 버전은 미확인입니다.
- `source.json`은 이미지 안의 49개 마커 번호·제목·좌표·코드·설명과 전체 2,096개 좌표 인덱스, 분류·변환·이미지 해시를 보관합니다. `review.json`은 모든 설명의 검토와 획득 목록·보류 이유를 보관합니다.
- 저장소 루트에서 아래 명령으로 재생성·대조합니다. 원본의 이후 변경과 검토 해석의 정확성은 자동 검증 대상이 아닙니다.

```bash
node reference-data/maps/generate.mjs ainsel-river
node reference-data/maps/generate.mjs ainsel-river --check
```

## 지형 정합과 범위

- 이미지 `src/assets/images/maps/6_ainsel_river.webp`, `2010×1350`. SHA-256과 변환 행렬은 원본 기록에 있습니다.
- 지하 지도도 `L.CRS.Simple`, 타일 256px, 최대 원본 줌 5인 동일 아틀라스에 있습니다. 타일 URL은 `https://edring.lsdl.kr/assets/maptiles/5/tile_{x}_{y}.jpg`, 수집 범위 x `3..5`, y `2..4`입니다.
- `u = sourceX × 32 - 768`, `v = -sourceY × 32 - 512`를 행렬에 넣고 가로 2010·세로 1350으로 나눕니다. 최종 값만 소수점 여섯 자리로 반올림합니다.
- SIFT 최대 16,000개, 대상 40% 축소, BFMatcher 비율 0.65, RANSAC 4px의 affine 정합입니다. 최초 783개 대응 후보 중 731개를 채택했으며 잔차 중앙값 0.89px, 95백분위 2.62px입니다.
- 별도 특징점 추출·시드 20의 20% 분리 검증에서 155개 모두 5px 이내, 중앙값 0.99px·95백분위 2.85px였습니다. 3×3 모든 구역에 검증점이 있습니다. 서쪽 유적·동쪽 우물·남쪽 수문 지형의 원본/대상 확대 대조도 확인했습니다.
- 배경 정합 오차와 LSDL 개별 마커의 실제 배치 오차는 별개입니다. 낮은 해상도의 원본 타일 확대에는 흐림이 남습니다.
- 최종 범위 49개 모두 반영, 제외·중복 ID 없음. 이름이 같은 우르의 왕조 유적과 축복/보스 녹스텔라의 용인병은 서로 다른 원본 ID를 유지합니다. 미분류·무명 마커는 없습니다.

## 획득 정보와 한계

- 설명 49개를 검토해 41개 마커에 획득 항목 44건을 연결했습니다. 미기재 수량을 1로 만들지 않습니다.
- 용인병의 얼음 뇌창, 아스테르의 날개, 궁병·진흙인간·밤무녀와 검사 꼭두각시, 지도 조각 등을 연결했습니다. 두 종류의 단석·은방울꽃이 묶인 대표점은 목록으로 유지합니다.
- `LSDL-2221`의 단석 [1]은 명시된 3개를 적용합니다. 등급 `[1]`과 석검 열쇠 소모량은 획득 수량이 아닙니다.
- `LSDL-1842`의 영혼 꽃 채취자의 방울 [2]만 획득품으로 연결하고 은방울꽃 1~3 판매 해금은 별도 취급합니다. 원본 코드 영혼묘도 유지합니다.
- `LSDL-2215`의 판매 재고·가격과 제작서의 해금 제작법은 현장 획득 목록에서 제외하고 원문에 보존합니다.
- `LSDL-2217`의 본류 접근 조건, `1843`의 석검 열쇠 봉인은 검토에 기록했습니다. 현재 목록 UI는 이런 접근 조건을 직접 표시하지 않습니다.
- 원본 `LSDL-953`의 노스텔라 표기를 임의로 고치지 않았습니다. 작은 라니 대화 단계는 획득품이 아닙니다.
- 인게임의 모든 개별 시체·상자·층과 수량을 검증한 자료는 아닙니다. 기존 다섯 지역·UI·DB·운영 데이터는 변경하지 않습니다.

## 검증

- 후보·원본·설명 검토·생성 결과 ID 집합과 정규화 좌표를 대조했습니다. 기존 다섯 지역 배열 전체가 Git HEAD와 동일하며 기존 생성 대상들의 재생성 대조도 통과했습니다.
- PC 기본 화면과 모바일 390×844에서 보스 보상, 단석 3개, 방울과 묶음 목록을 확인했습니다. 같은 이름의 축복·보스는 키보드로 구분해 선택했습니다.
- 모바일 최대 8배에서 단석 직접 클릭·목록, 드래그·닫기·전체 보기 복귀를 확인했습니다. 전체 보기 49개 렌더링, 선택 해제 0개, 가로 넘침과 브라우저 오류 로그 없음도 확인했습니다. 실제 Android/iOS 기기는 확인하지 않았습니다.
- lint·typecheck·변경 파일 포맷·diff·재생성 대조를 통과했습니다. 라우트·빌드 설정·서버/클라이언트 경계 변경은 없습니다.
