# 겔미어 화산 지도 수집 기록

지역 ID `12`, 개발 모드 `/maps/12`용 데이터입니다. [수집 기준](../../../docs/MAP_DATA_IMPORT.md)을 따릅니다. 화산관·라이드 요새·화산 능선과 이미지에 보이는 그늘성·알터 고원 일부를 범위 기준으로 수집합니다.

## 출처와 재생성

- [LSDL 본편 공개 지도](https://edring.lsdl.kr/map)와 [분류 스크립트](https://edring.lsdl.kr/assets/js/map.js), 확인일 `2026-11-21`. 적용 게임 버전은 미확인입니다.
- `source.json`: 이미지 범위의 158개 원본 번호·제목·좌표·코드·설명, 전체 2,096개 좌표 인덱스, 분류·이미지 해시·변환·검증 지표입니다.
- `review.json`: 모든 설명의 검토·획득 목록·수량·보류 이유입니다. 알터 고원과 겹치는 143개는 원본 필드 전체가 같은지 확인하고 검토·항목 순서를 재사용했습니다. 나머지 15개는 새로 검토했습니다.
- 공통 생성기로 저장 자료와 생성 결과를 대조합니다. 이후 사이트 변경과 사람의 해석 정확성은 자동 검증 대상이 아닙니다.

```bash
node reference-data/maps/generate.mjs mt-gelmir
node reference-data/maps/generate.mjs mt-gelmir --check
```

## 지형과 좌표 정합

- 이미지 `src/assets/images/maps/12_mt_gelmir.webp`, `3270×2940`. SHA-256과 변환 행렬은 원본 기록에 있습니다. 별도 삽입 영역 없는 연속된 지형입니다.
- 원본 `L.CRS.Simple`, 줌 5·타일 256px. `https://edring.lsdl.kr/assets/maptiles/5/tile_{x}_{y}.jpg`의 x `5..11`, y `5..11`을 사용합니다.
- `u = sourceX × 32 - 1280`, `v = -sourceY × 32 - 1280`을 행렬에 넣고 가로 3270·세로 2940으로 나눕니다. 최종 값만 소수점 여섯 자리로 반올림하며 경계로 잘라 넣지 않습니다.
- SIFT 최대 16,000개, 대상 이미지 40% 축소, BFMatcher 비율 0.65, affine RANSAC 4px로 추정했습니다. 최초 3,275개 대응 후보 중 3,273개를 채택했고 잔차 중앙값 0.46px·95백분위 1.52px입니다.
- 별도 특징점 추출·시드 20의 20% 분리 검증에서는 659개 모두 5px 이내, 중앙값 0.50px·95백분위 1.64px·최대 3.20px였습니다. 3×3 모든 구역에 검증점이 있고 각 구역 95백분위는 약 1.30~3.04px입니다.
- 서쪽 라이드 요새·북쪽 산 능선·동쪽 절벽·남쪽 지형의 원본/대상 확대 대조도 확인했습니다. 배경 정합과 개별 마커의 실제 게임 배치·층 정확도는 별개이며 원본 타일 확대 흐림은 남습니다.

- 최종 후보 158개 모두 반영, 제외·중복 ID 없음. 원본 분류가 없는 41개도 유지하고 무명 마커는 없습니다. 같은 이름의 장소·축복·보스·개별 아이템을 원본 ID로 구분합니다.
