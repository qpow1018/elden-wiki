# 시프라 강 지도 수집 기록

지역 ID `7`, 개발 모드 `/maps/7`용 데이터입니다. [수집 기준](../../../docs/MAP_DATA_IMPORT.md)을 따릅니다. 보유 이미지에 보이는 영원한 도읍 노크론·밤의 성역·시프라 수도교도 포함합니다.

## 출처와 재생성

- [LSDL 본편 공개 지도](https://edring.lsdl.kr/map)와 [분류 스크립트](https://edring.lsdl.kr/assets/js/map.js), 확인일 `2026-11-21`. 적용 게임 버전은 미확인입니다.
- `source.json`에는 이미지 범위의 125개 원본 번호·제목·좌표·코드·설명, 전체 2,096개 좌표 인덱스, 분류·이미지 해시·변환 행렬을 보관합니다. `review.json`에는 모든 설명의 검토와 획득 목록·보류 이유가 있습니다.
- 아래 명령은 저장된 자료와 생성 결과의 일치를 검증합니다. 이후 사이트 변경이나 해석 정확성까지 자동 검증하지 않습니다.

```bash
node reference-data/maps/generate.mjs siofra-river
node reference-data/maps/generate.mjs siofra-river --check
```

## 지형 정합과 범위

- 이미지 `src/assets/images/maps/7_siofra_river.webp`, `2880×2850`. SHA-256과 변환 행렬은 원본 기록에 보존합니다.
- 원본은 `L.CRS.Simple`, 타일 256px, 최대 원본 줌 5입니다. `https://edring.lsdl.kr/assets/maptiles/5/tile_{x}_{y}.jpg`의 x `24..27`, y `19..23`을 사용합니다.
- `u = sourceX × 32 - 6144`, `v = -sourceY × 32 - 4864`를 행렬에 넣고 가로 2880·세로 2850으로 나눕니다. 최종 값만 소수점 여섯 자리로 반올림하며 경계로 잘라 넣지 않습니다.
- SIFT 최대 16,000개, 대상 이미지 40% 축소, BFMatcher 비율 0.65, affine RANSAC 4px로 추정했습니다. 최초 5,295개 대응 후보 중 4,914개를 채택했고 잔차 중앙값 0.61px·95백분위 1.85px입니다.
- 별도 특징점 추출 후 시드 20으로 20%를 분리한 검증에서는 1,041개 중 1,040개가 5px 이내였습니다. 전체 중앙값 0.63px·95백분위 2.04px이며 1개는 약 940px의 큰 불일치점입니다. 3×3 모든 구역에 검증점이 있고 각 구역의 95백분위는 약 1.60~2.26px입니다.
- 서남쪽 노크론 건물·북동쪽 절벽·남쪽 각해의 영지 계단의 원본/대상 확대 지형도 대조했습니다. 타일 확대 흐림과 개별 마커의 게임 배치 오차는 배경 정합 오차와 별개입니다.
- 최종 후보 125개 전부 반영, 제외·중복 ID 없음. 원본 필터가 없는 34개와 무명 `LSDL-1736`도 유지합니다. 장소·축복·보스와 동명 개별 아이템은 원본 번호로 구분합니다.

## 획득 정보와 보류

- 설명 125개를 검토해 81개 마커에 획득 항목 90건을 연결했습니다. 명시되지 않은 수량을 1로 채우지 않습니다.
- 화신의 물방울은 물방울 유생 2개·은 물방울 가면, 가고일은 대검·쌍날검, 밤의 성역 상자는 손가락 죽임의 칼날·큰 영혼 묘 은방울 꽃을 연결했습니다.
- 선조령의 왕은 추억만 연결하며 룬 환산·교환품·가격은 제외합니다. 선조령 `1130`은 원본에 진입 조건만 있고 보상명이 없어 추정 보상을 넣지 않았습니다.
- 무명 `1736`은 설명의 뒤집힌 매 히터 실드·아르테리아의 잎을 연결합니다. 두 등급의 은방울꽃, 단석·기사 처치 보상 등은 원본 대표점의 목록을 유지하며 개별 층·상자 좌표는 추정하지 않습니다.
- 깃든 화살 10개, 유생나비 3개 및 7+1=8개, 은방울꽃 [3] 2개, 황금 지네 2개 등 명시된 수량만 적용합니다. HP 660·저항력 40·중량 0.9·석검 열쇠 소모량·봉화 개수는 획득 수량이 아닙니다.
- 상인 `1004`의 재고·가격, 제작서의 해금 제작법, 방울의 판매 해금은 획득품과 분리합니다. 방울 `1747`의 제목 [1]과 설명의 은방울꽃 1~3 범위는 미확인 정합으로 기록합니다.
- D `2775`의 조건부 제스처·소환, `2296`의 랜덤 드롭과 반복 채집, `2741`의 반복 파밍, 블라이드 대화는 원문과 보류 이유에 보존합니다.
- 제작서 [6] `1737`과 `2929`는 동명·다른 위치인 원본 두 개를 유지합니다. 실제 중복 배치 여부는 미확인입니다.
- `2994`는 원본 제목이 녹스텔라의 용인병이나 시프라 좌표와 용 할버드 보상이 적혀 있습니다. 제목과 보상은 원문대로 보존하고 불일치를 기록합니다.
- 전송문 `3000`, `3001`의 제목과 설명 목적지가 반대입니다. 원본 표기를 유지하고 목적지는 미확인으로 남깁니다. 지도 조각의 시오프라 표기도 유지합니다.
- 본류·하층·전송문·석검 봉인 등의 접근 조건은 원문·검토에 남지만 현재 목록 UI에는 직접 표시되지 않습니다. 인게임 모든 물품·수량·개별 층을 검증한 자료는 아닙니다.

## 검증

- 후보·원본·검토·생성 결과 ID 집합과 정규화 좌표를 대조했습니다. 기존 여섯 지역 배열 전체가 Git HEAD와 동일하며 기존 생성 대상의 재생성 대조도 통과했습니다.
- PC 기본 화면에서 화신의 물방울 수량과 가면, 선조령의 왕의 추억을 확인했습니다. 모바일 390×844에서 무명 마커의 두 아이템과 가고일의 두 무기를 확인했습니다. 동명 축복과 보스 중 보스를 키보드로 지정해 보상 목록을 확인했습니다.
- 모바일 최대 8배에서 얼룩색 목걸이 +1 직접 클릭·목록, 드래그·닫기·전체 보기 복귀를 확인했습니다. 전체 보기 125개 렌더링, 선택 해제 0개, 가로 넘침과 브라우저 오류 로그 없음도 확인했습니다. 실제 Android/iOS 기기는 확인하지 않았습니다.
- lint·typecheck·포맷·diff·재생성 대조를 통과했습니다. 기존 여섯 지역·마커 UI·DB·운영 데이터는 변경하지 않았습니다. 라우트·빌드 설정·서버/클라이언트 경계 변경은 없습니다.
