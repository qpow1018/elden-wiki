# 도감 데이터 출처와 등록 기준

개별 자료의 출처·변환·충돌 해결과 등록 계획을 기록합니다. 실제 값과 순서는 시드 SQL, 공통 저장 규칙은 [DATABASE.md](DATABASE.md), 미확인 항목과 확인 결과는 [DATA_VERIFICATION.md](DATA_VERIFICATION.md)를 기준으로 합니다. 작업별 검증 결과나 환경별 반영 보고는 누적하지 않습니다.

## 출처 선택 원칙

- 기본 출처는 사용자가 제공한 나무위키 복사 자료입니다. 원문에 없는 수치는 [ThomasJClark 무기 계산기](https://github.com/ThomasJClark/elden-ring-weapon-calculator)의 일반 게임 데이터로 보완합니다.
- 보완 출처가 제공하지 않는 필드는 미확인으로 유지하고, 충돌하는 값은 자동으로 덮어쓰지 않습니다. 채택한 근거를 해당 자료 절에 기록합니다.
- 서비스는 최신 게임 상태를 목표로 갱신하며 별도 적용 버전은 관리하지 않습니다. 재현에 필요한 원본 URL·파일 식별 정보는 보존합니다.
- 새 자료는 관련 절에 통합합니다. 시드의 전체 수치표·설명·등록 완료 건수를 복제하지 않습니다.

## 무기 도감 등록 범위

- 사용자 목록을 무기(`weapon`: 단검~쌍날검 30개 분류), 촉매(`catalyst`: 지팡이·성인 2개 분류), 기타 무기(`other_weapon`: 원거리·횃불·방패 10개 분류)로 나눕니다. 화살·대형 화살·볼트·대형 볼트는 보류합니다.
- 아래 순서는 사용자의 전달 순서입니다. 분류 `sort_order`는 최초 등록한 10부터 420까지의 값을 유지하고 각 타입 안에서 정렬하며, 개별 아이템은 추후 각 분류 내 전달 순서대로 등록합니다.
- 총 42개 분류, 등록 예정 항목 487개입니다. 수량은 사용자 목록의 항목 수이며, 공식 전체 장비 수나 최신 버전의 완전성을 검증한 값이 아닙니다.
- 출처는 사용자 제공 목차입니다. 일부 원문 링크는 [특대형 무기](https://namu.wiki/w/엘든%20링/무기/특대형%20무기), [촉매](https://namu.wiki/w/엘든%20링/무기/촉매)이며 외부 원문·게임 버전·DLC 소속은 아직 대조하지 않았습니다.

## 단검 등록 자료

- `supabase/seeds/weapons/daggers.sql`은 사용자가 제공한 [소형 무기 목차·본문](https://namu.wiki/w/엘든%20링/무기/소형%20무기)의 복사 자료에서 단검 18종을 등록합니다. 순서와 한글명은 사용자 목록을 따릅니다. 별도 외부 수치로 보완하지 않았습니다.
- `supabase/config.toml`에서 분류 시드 다음에 단검 시드를 실행합니다. 아이템·상세·기술·보정의 기존 행은 건너뛰며 기존 순서 변경을 덮어쓰지 않습니다. 이름은 이번 자료의 조회에만 사용하고, 중복 이름으로 조회가 모호하면 중단합니다. ID를 고정하지 않습니다.
- 공격력·가드 성능은 자료에 명시된 최대 강화 수치, 변질 가능 무기는 표준 기준입니다. 보정은 변질별 최대 강화 등급이며, `D - B`처럼 기본→최대 표기는 마지막 등급을 사용합니다. 자료의 `상질`은 기존 코드 `quality`(표시명 상질)에 대응합니다.
- 숫자 칸의 `-`는 없음(`0`), 보정 등급의 `-`는 보정 없음으로 저장합니다. 표에 없는 수면·발광은 사용자 공통 기준에 따라 없음(`0`)으로 저장합니다.
- 변질 가능 10종은 변질표, 변질 불가 8종은 단일 보정표와 본문을 근거로 합니다. 미확인 보정·상태 이상과 확인 조건은 [데이터 확인 목록](DATA_VERIFICATION.md)에 정리하며, 확인 전에는 `NULL`을 유지합니다.
- 상아 손낫·결정 나이프는 단석 강화이지만 변질 불가입니다. 나머지 색잃은 단석 무기와 구분하며, 강화 재료만으로 변질 가능 여부를 결정하지 않습니다.
- 패리 FP는 원문에서 패링 대거 `-`, 맹고슈 `3`으로 충돌합니다. 사용자 확인에 따라 공통 전투 기술 패리의 소비 FP를 `3`으로 통일합니다. 협차의 `퀵 스텝`은 동일 원문의 기술 설명에 맞춰 `퀵스텝`으로 통일합니다.
- 게임 내 설명과 기술 설명만 분리해 저장하며 평가·운용·획득 공략은 저장하지 않습니다. 숫자 각주는 원문 연결 정보가 없어 제거합니다.
- 부가 효과는 사용자 제공 본문에서 축제의 손낫(가드 관통 성격·명중 시 룬 10), 친퀘디아(짐승 기도 위력 10%), 불의 기사 단검(화염 공격력 부여 시 상승 효과)을 요약합니다. 전투 기술 효과를 무기 자체의 상시 부가 효과로 중복 등록하지 않습니다.
- 불의 기사 단검·맹고슈는 자료의 DLC 표시에 따라 `shadow_of_the_erdtree`, 나머지 16종은 제공 목차의 본편 분류에 따라 `base_game`으로 등록합니다. 이미지 주소는 제공되지 않아 전부 `NULL`입니다.

## 투척검 등록 자료

- `supabase/seeds/weapons/throwingBlades.sql`에서 사용자 제공 [유문 단검 본문](https://namu.wiki/w/엘든%20링/무기/소형%20무기#s-3.1)을 기준으로 투척검 분류의 첫 항목을 등록합니다. 단검 분류와 구분합니다.
- 게임 내 설명·기술 설명은 제공된 인용문을 보존합니다. 기본 기술은 관통 투척, 강화 재료는 단석, 변질 가능은 본문의 명시를 따릅니다. DLC 표시에 따라 `shadow_of_the_erdtree`로 등록합니다.
- 사용자 자료에 없는 수치는 [ThomasJClark 계산기의 일반 게임 데이터](https://github.com/ThomasJClark/elden-ring-weapon-calculator/blob/master/public/regulation-vanilla-v1.17.js)로 보완합니다. 원본 URL과 SHA-256은 시드에 기록합니다. 모드용 데이터는 사용하지 않습니다.
- 원본에 상태 이상 파라미터 참조가 없으면 기본 축적 없음으로 해석합니다. 실제 등록 수치는 시드 SQL을 기준으로 합니다.
- [원본 강화 계산](https://github.com/ThomasJClark/elden-ring-weapon-calculator/blob/master/src/regulationData.ts)에 따라 미강화 공격력·보정 계수에 최대 강화 계수를 곱합니다. 공격력은 정수 표시를 위해 소수점 아래를 버리고 캐릭터 보정·버프를 더하지 않습니다. 보정 등급은 원본 `scalingTiers`로 변환합니다.
- 중량·치명·가드·공격 방식·기술 FP는 계산기 데이터에 없어 `NULL`을 유지합니다. 누락된 정보는 [데이터 확인 목록](DATA_VERIFICATION.md)에 기록합니다.
- 이미지 링크는 제공됐지만 이미지 등록은 보류합니다. 별도 재사용 허락·이용 조건이 확인된 이미지를 추후 사용합니다. 평가·운용 공략·인챈트 불가 설명은 게임 내 원문에 섞지 않으며 이번에 별도 필드를 추가하지 않습니다.
- 분류·단검 시드 다음에 투척검 시드를 실행합니다. 기본 등록은 기존 행과 표시 순서를 보존하며, 계산기로 보완한 수치는 `NULL`인 칸만 채웁니다. 기존 보정 행은 덮어쓰지 않습니다.
