# 도감 데이터 확인 목록

사용자가 추후 실제 인게임에서 확인해 보완할 항목입니다. 아래 내용은 사용자 제공 자료와 보완 출처 기준이며, 확인이 끝나기 전에는 DB와 시드의 미확인 값을 유지합니다.

수면·발광 항목이 자료 표에 없으면 사용자 기준에 따라 축적 수치를 `0`으로 저장합니다. 이 경우는 미확인 항목에 포함하지 않습니다. 일반 입력 기준은 [DATABASE.md](DATABASE.md)에서 관리합니다.

## 불의 기사 단검·맹고슈: 변질별 능력 보정

- 상태: **인게임 확인 대기**
- 대상: `weapon_scalings`의 `strength`, `dexterity`, `intelligence`, `faith`, `arcane`
- 사유: 제공된 표에서 표준 외 모든 변질의 등급이 `-`로만 채워져 있어 실제 보정 없음으로 확정하지 않았습니다.
- 현재 저장: 표준 보정은 제공값 유지. 아래 각 변질의 다섯 능력치 등급은 모두 `NULL`입니다.
- 확인 조건: 각 무기의 최대 강화 상태에서 해당 변질을 적용한 뒤, 다섯 능력치의 보정 등급을 확인합니다. 변질 자체가 불가능하다면 등급 없음으로 채우지 말고 그 사실을 기록합니다.

## 사명의 칼날·검은 칼날: 기본 상태 이상 축적

- 사유: 제공된 표는 다른 단검과 달리 ‘최대 강화 기준’으로 표시되어 있습니다. DB는 미강화 기본 수치를 저장하므로 기준을 바꿔 해석하지 않았습니다.

- 묘지기 새의 갑옷: 제공된 갑옷 묶음 설명에는 깃털 망토·점프 공격 강화가 있어 깃털 갑옷에만 사용했습니다. 일반 갑옷의 `game_description`은 `NULL`이며 별도 원문을 확인해야 합니다.
- 수치·부가 효과는 이번 등록 범위에서 제외했으므로 해당 필드의 미등록을 데이터 확인 누락으로 추가하지 않습니다. [채택 기준](DATA_SOURCES.md#방어구-분류-56-이름부위게임-내-설명)을 참고합니다.

## 방어구 분류 7: 설명 누락

- 상태: **별도 원문 또는 인게임 확인 대기**
- 메스메르 병사의 갑옷(경장): 묶음 설명은 망토를 묘사하지만 경장에는 천이 제거된다고 되어 있어 경장 설명을 `NULL`로 두었습니다.
- 기이한 기사의 후드(경장): 제공 설명은 후드가 있는 일반형이며 경장은 후드가 사라져 별도 설명을 확인해야 합니다. 현재 `NULL`입니다.
- 메스메르의 투구(경장): 본문에 일반형과 경장의 설명 차이·번역 누락이 명시되어 경장 고유 원문을 확인해야 합니다. 현재 `NULL`입니다.
- 수치·별도 부가 효과는 이번 범위에서 제외했습니다. [채택 기준](DATA_SOURCES.md#방어구-분류-7-이름부위게임-내-설명)을 참고합니다.

## 방어구 분류 8: 설명 누락

- 상태: **별도 원문 또는 인게임 확인 대기**
- 불의 기사의 갑옷(경장): 제공 묶음 설명은 붉은 망토와 메스메르 불 기도 강화를 포함하나 본문은 경장 시 망토가 없어지고 특수 효과도 일반형에만 있다고 명시합니다. 경장 전용 게임 내 설명 확인 전까지 `game_description`은 `NULL`입니다.

## 이미지 등록 보류

이미지는 추후 재사용이 허용된 자료와 이용 조건을 확인한 뒤 등록합니다. 현재 등록한 무기의 `image_url`은 `NULL`입니다. 인게임 수치 확인 항목과 구분합니다.

## 확인 결과 기록과 반영

서비스는 항상 최신 게임 상태를 목표로 갱신하며 별도 게임 버전은 관리하지 않습니다.

확인한 항목별로 다음 정보를 남깁니다.

- 확인일·플랫폼
- 무기명·강화 단계·변질·버프 유무, 축적 수치에 영향을 줄 수 있는 캐릭터 능력치
- 확인한 등급·수치와 스크린샷 등 근거
- 로컬 DB·시드 반영 여부와 운영 반영 여부

확인 후 해당 무기의 시드 SQL과 실제 로컬 DB를 함께 수정하고, 조회 결과를 확인한 다음 해당 항목을 완료로 표시합니다. 시드마다 기존 행의 갱신 정책이 다르므로 시드 수정만으로 현재 DB가 갱신된다고 가정하지 않습니다. 확인이 끝난 항목도 근거와 반영 이력을 남깁니다.
