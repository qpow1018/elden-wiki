# 도감 데이터 확인 목록

사용자가 추후 실제 인게임에서 확인해 보완할 항목입니다. 아래 내용은 2026-11-03 등록한 단검 자료 기준이며, 확인이 끝나기 전에는 DB와 시드의 미확인 값을 유지합니다.

수면·발광 항목이 자료 표에 없으면 사용자 기준에 따라 축적 수치를 `0`으로 저장합니다. 이 경우는 미확인 항목에 포함하지 않습니다. 일반 입력 기준은 [DATABASE.md](DATABASE.md)에서 관리합니다.

## 불의 기사 단검·맹고슈: 변질별 능력 보정

- 상태: **인게임 확인 대기**
- 대상: `weapon_scalings`의 `strength`, `dexterity`, `intelligence`, `faith`, `arcane`
- 사유: 제공된 표에서 표준 외 모든 변질의 등급이 `-`로만 채워져 있어 실제 보정 없음으로 확정하지 않았습니다.
- 현재 저장: 표준 보정은 제공값 유지. 아래 각 변질의 다섯 능력치 등급은 모두 `NULL`입니다.
- 확인 조건: 각 무기의 최대 강화 상태에서 해당 변질을 적용한 뒤, 다섯 능력치의 보정 등급을 확인합니다. 변질 자체가 불가능하다면 등급 없음으로 채우지 말고 그 사실을 기록합니다.

## 사명의 칼날·검은 칼날: 기본 상태 이상 축적

- 상태: **인게임 확인 대기**
- 대상: `weapon_details`의 `scarlet_rot`, `frostbite`, `bleed`, `poison`
- 사유: 제공된 표는 다른 단검과 달리 ‘최대 강화 기준’으로 표시되어 있습니다. DB는 미강화 기본 수치를 저장하므로 기준을 바꿔 해석하지 않았습니다.
- 현재 저장: 두 무기의 위 네 수치는 모두 `NULL`입니다. 수면·발광은 공통 기준에 따라 `0`입니다.
- 확인 조건: 미강화·기본 상태에서 일시적 버프를 제외한 무기 자체 축적 수치를 확인합니다. 전투 기술의 효과와 구분합니다.

| 무기        | 붉은 부패 | 동상   | 출혈   | 독     |
| ----------- | --------- | ------ | ------ | ------ |
| 사명의 칼날 | 미확인    | 미확인 | 미확인 | 미확인 |
| 검은 칼날   | 미확인    | 미확인 | 미확인 | 미확인 |

## 적용 버전과 자료 누락

- 단검 18종의 원자료에는 표 수치가 적용되는 게임 버전이 명시되지 않았습니다. 해설에 등장하는 패치 번호를 표 전체의 적용 버전으로 간주하지 않습니다. 현재 데이터가 최신 패치와 일치하는지는 별도 확인이 필요합니다.
- 이미지 주소는 18종 모두 미제공으로 `game_items.image_url = NULL`입니다. 이는 인게임 수치 검증과 별도로 보완할 자료 누락입니다.

## 확인 결과 기록과 반영

확인한 항목별로 다음 정보를 남깁니다.

- 확인일·플랫폼·게임 버전(가능하면 앱 버전과 레귤레이션 버전)
- 무기명·강화 단계·변질·버프 유무, 축적 수치에 영향을 줄 수 있는 캐릭터 능력치
- 확인한 등급·수치와 스크린샷 등 근거
- 로컬 DB·시드 반영 여부와 운영 반영 여부

확인 후 `supabase/seeds/weapons/daggers.sql`과 실제 로컬 DB를 함께 수정하고, 조회 결과를 확인한 다음 해당 항목을 완료로 표시합니다. 시드는 기존 행을 덮어쓰지 않으므로 시드 수정만으로 현재 DB가 갱신되지는 않습니다. 확인이 끝난 항목도 근거와 반영 이력을 남깁니다.
