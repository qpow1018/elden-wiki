# 도감 데이터 확인 목록

게임 원본 CSV 대조로 해결할 수 있는 무기 수치는 분류별로 전수 검수합니다. 이 문서에는 별도 게임 텍스트, 인게임 동작 확인, 추가 자료가 필요한 항목만 기록합니다.

## 나찰의 대도: 받는 피해 증가

- 상태: **인게임 확인 대기**
- 사유: 제공 본문에 공격 중 받는 피해 10% 증가와 이후 PvP에서 추가 증가한 조정이 함께 언급되어 있습니다.
- 현재 저장: 공격 중 경직 저항·받는 피해 증가를 수치 없이 부가 효과로 제공합니다. 모드별 수치를 추정하거나 공통 10%로 표시하지 않습니다.
- 확인 조건: PvE·PvP, 공격 중·비공격 상태를 구분하고 동일 방어구·버프·공격 조건에서 받는 피해를 비교합니다. 확인 전에는 원문 정성 설명을 유지합니다.

## 무기 부가 효과 추가 확인

- 하이랜드 액스의 샤브리리의 외침 적용 여부와 프레이야의 대검·큰 뿔 망치·벌레의 글레이브·묘지의 대낫의 양손 장착 시 중첩은 인게임에서 확인합니다.
- 특정 적에 대한 추가 피해와 언데드 부활 방지는 대상 분류·실제 동작과 함께 검증합니다. 차지·점프·마상 공격 배율과 가드 관통은 관련 타격을 동작과 연결해 확인합니다. 해당 조건을 확인하기 전까지는 기존 설명의 출처를 따릅니다.

## 성인 부가 효과 확인

- 신 사냥의 성인의 흑염 지속 피해 제외는 기존 문구를 유지합니다. 같은 대상과 능력치에서 성인 장착 여부에 따른 최초 타격과 지속 피해를 나눠 인게임에서 확인합니다.

## 횃불: 특수 효과 확인

- 보초의 횃불: 본문에 기재된 ‘현자의 동굴의 환영벽을 해제한다’는 효과는 추가 확인이 필요해 부가 효과에 확정 등록하지 않았습니다. 횃불 소지·장착·접근만으로 해제되는지 일반 공격에 의한 해제와 구분해 확인합니다.

## 방패: 부가 효과 확인

- 일식 문양 대형 방패: 부가 효과 목록은 면역·강건·이성 50, 본문은 모든 상태 이상 내성 50입니다. 항사 등 나머지 내성에도 적용되는지 확인하며 현재 명시된 3종만 설명에 사용합니다.

## 방어구 분류 5·6: 설명 누락

- 상태: **별도 원문 또는 인게임 확인 대기**
- 티에리에의 옷(경장): 제공된 일반·경장 묶음 설명은 신비 증가를 포함하나 본문에는 경장 시 효과가 사라진다고 되어 있어 `game_description`을 `NULL`로 두었습니다. 경장 전용 설명을 확인합니다.
- 묘지기 새의 갑옷: 제공된 갑옷 묶음 설명에는 깃털 망토·점프 공격 강화가 있어 깃털 갑옷에만 사용했습니다. 일반 갑옷의 `game_description`은 `NULL`이며 별도 원문을 확인해야 합니다.
- 수치·부가 효과는 이번 등록 범위에서 제외했으므로 해당 필드의 미등록을 데이터 확인 누락으로 추가하지 않습니다. [채택 기준](DATA_SOURCES.md#방어구-분류-56-이름부위게임-내-설명)을 참고합니다.

## 방어구 분류 7: 설명 누락

- 상태: **별도 원문 또는 인게임 확인 대기**
- 메스메르 병사의 갑옷(경장): 묶음 설명은 망토를 묘사하지만 경장에는 천이 제거된다고 되어 있어 경장 설명을 `NULL`로 두었습니다.
- 기이한 기사의 후드(경장): 제공 설명은 후드가 있는 일반형이며 경장은 후드가 사라져 별도 설명을 확인해야 합니다. 현재 `NULL`입니다.
- 메스메르의 투구(경장): 본문에 일반형과 경장의 설명 차이·번역 누락이 명시되어 경장 고유 원문을 확인해야 합니다. 현재 `NULL`입니다.
- 수치·별도 부가 효과는 이번 범위에서 제외했습니다. [채택 기준](DATA_SOURCES.md#방어구-분류-7-이름부위게임-내-설명)을 참고합니다.

## 방어구 분류 8: 설명 누락

- 상태: **별도 원문 또는 인게임 확인 대기**
- 불의 기사의 갑옷(경장): 제공 묶음 설명은 붉은 망토와 메스메르 불 기도 강화를 포함하나 본문은 경장 시 망토가 없어지고 특수 효과도 일반형에만 있다고 명시합니다. 경장 전용 게임 내 설명 확인 전까지 `game_description`은 `NULL`입니다.
- 수치·별도 부가 효과는 이번 범위에서 제외했습니다. [채택 기준](DATA_SOURCES.md#방어구-분류-8-이름부위게임-내-설명)을 참고합니다.

## 방어구 분류 10·11: 등록 보류

- 상태: **추가 원문 대기**
- 강철 세트: 전달 자료에는 이미지 캡션·입수 방법·성능 해설만 있고 개별 장비 이름과 게임 내 설명이 없습니다. 개별 장비 행은 등록하지 않았습니다. 각 부위의 실제 이름과 게임 내 설명을 받은 뒤 기존 순서 사이에 등록합니다.
- 자료의 `[TE]` 표기는 보존하되 추정한 이름·설명이나 수치로 채우지 않습니다. [채택 기준](DATA_SOURCES.md#방어구-분류-1011-이름부위게임-내-설명)을 참고합니다.

## 이미지 등록 보류

이미지는 추후 재사용이 허용된 자료와 이용 조건을 확인한 뒤 등록합니다. 현재 등록한 무기의 `image_url`은 `NULL`입니다. 인게임 수치 확인 항목과 구분합니다.

## 전회: 제공된 게임 내 설명의 누락·조건 불일치

- 상태: **인게임 확인 대기**
- 대상: `game_items.game_description`. 제공문을 그대로 저장했으며, 아래 부분을 추정해 수정하지 않았습니다.
- 영혼 불꽃 부르기: ‘무기를 내밀어 영혼 불꽃을 · / 불꽃을 부르는 전투 기술.’로 문장이 끊겨 있습니다. 인게임 전회 설명에서 해당 문장 전체를 확인합니다.
- 폭풍의 칼날: ‘모든 표준, 참격 무기에 사용 가능하다.’와 ‘검에 사용 가능. (특대형 무기/쌍날검 제외)’가 함께 제공됩니다. 인게임 설명의 실제 사용 가능 무기·제외 조건을 확인합니다.
- 확인 후 `supabase/seeds/ashesOfWar/ashesOfWar.sql`과 실제 DB의 해당 설명을 함께 수정합니다. 전용 상세 필드는 이번 등록 범위가 아니므로 미입력 상태를 유지합니다.
