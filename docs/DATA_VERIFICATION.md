# 도감 데이터 확인 목록

사용자가 추후 실제 인게임에서 확인해 보완할 항목입니다. 아래 내용은 2026-11-03 등록한 단검·투척검·채찍·주먹·격투·손톱·짐승 발톱·조향병·자검 자료 기준이며, 확인이 끝나기 전에는 DB와 시드의 미확인 값을 유지합니다.

수면·발광 항목이 자료 표에 없으면 사용자 기준에 따라 축적 수치를 `0`으로 저장합니다. 이 경우는 미확인 항목에 포함하지 않습니다. 일반 입력 기준은 [DATABASE.md](DATABASE.md)에서 관리합니다.

- 대상: `weapon_scalings`의 `strength`, `dexterity`, `intelligence`, `faith`, `arcane`
- 사유: 제공된 표에서 표준 외 모든 변질의 등급이 `-`로만 채워져 있어 실제 보정 없음으로 확정하지 않았습니다.

## 사명의 칼날·검은 칼날: 기본 상태 이상 축적

- 대상: `weapon_details`의 `scarlet_rot`, `frostbite`, `bleed`, `poison`
- 사유: 제공된 표는 다른 단검과 달리 ‘최대 강화 기준’으로 표시되어 있습니다. DB는 미강화 기본 수치를 저장하므로 기준을 바꿔 해석하지 않았습니다.

## 유문 단검: 남은 미확인 정보

- 무기 정보: 중량·물리 공격 방식
- 전투 수치: 치명·최대 강화 기본 상태의 가드 경감률 5종·가드 강도
- 전투 기술: 관통 투척의 소비 FP
- 현재 저장: 위 항목은 `NULL`입니다. 공개 계산기 데이터에는 해당 필드가 없습니다.
- 보완 완료: 표준 최대 강화 공격력 5종, 필요 능력치 5종, 기본 상태 이상, 최대 강화 변질별 보정 13행. [출처와 변환 기준](DATA_SOURCES.md#투척검-등록-자료)은 데이터 출처 문서에서 관리합니다.
- 사용자 제공 설명·단석 강화·변질 가능·DLC 소속과 순서는 유지합니다.

## 이빨 채찍: 누락 정보

- 상태: **추가 자료 또는 인게임 확인 대기**
- 대상: 중량·물리 공격 방식·치명·최대 강화 가드 경감률 5종·가드 강도·통타 소비 FP
- 사유: 사용자 자료에 수치표가 없고 계산기 원본에도 해당 필드가 없습니다.
- 현재 저장: 위 필드는 `NULL`입니다. 다른 채찍의 수치를 대입하지 않습니다.
- 확인 조건: 기본 상태의 최대 강화 무기 정보·가드·기술 FP를 확인합니다. 공격력·보정·필요 능력치·기본 축적은 계산기 자료로 보완했습니다.

## 채찍: 공격력 출처 차이

- 상태: **인게임 확인 대기**
- 대상과 차이: [출처 문서](DATA_SOURCES.md#채찍-등록-자료)의 비교표를 참고합니다.
- 현재 저장: 사용자 제공 나무위키 수치를 유지합니다. 최신 수치 일치 여부는 확정하지 않았습니다.
- 확인 조건: 표준 변질 또는 변질 불가 기본 상태의 최대 강화에서 캐릭터 보정으로 더해지는 수치·버프를 제외한 기본 공격력을 확인합니다. 물리와 화염을 구분합니다.

## 파타: 가드 강도

- 상태: **인게임 확인 대기**
- 제공 자료: 최대 강화 가드 강도 `31.2`
- 현재 저장: `guard_boost = NULL`. DB는 정수이므로 임의 반올림·절삭하지 않습니다.
- 확인 조건: 표준 변질·최대 강화에서 실제 표시되는 가드 강도를 확인합니다. 소수가 실제로 필요한 값이라면 해당 근거를 바탕으로 저장 자료형도 재검토합니다.

## 주먹: 수치표가 없는 4종

- 상태: **추가 자료 또는 인게임 확인 대기**
- 대상: 독의 손·미친 손·티에리에의 숨긴 침·골렘의 주먹
- 공통 누락: 중량·물리 공격 방식·치명·최대 강화 가드 경감률 5종·가드 강도
- 기술 FP 누락: 독 관수·발광 관수·영원히 잠들라. 골렘의 주먹은 자료에 명시된 공통 기술 참기를 연결합니다.
- 현재 저장: 누락 필드는 `NULL`. 공격력·필요 능력치·기본 상태 이상·최대 강화 보정은 [계산기 보완 기준](DATA_SOURCES.md#주먹-등록-자료)에 따라 등록합니다.
- 확인 조건: 기본 상태 또는 표준 변질의 최대 강화에서 무기 정보·가드·기술 FP를 확인합니다. 기본 축적은 미강화·캐릭터 보정·버프 제외 기준으로 확인합니다.

## 이미지 등록 보류

이미지는 추후 재사용이 허용된 자료와 이용 조건을 확인한 뒤 등록합니다. 현재 등록한 무기의 `image_url`은 `NULL`입니다. 인게임 수치 확인 항목과 구분합니다.

## 확인 결과 기록과 반영

서비스는 항상 최신 게임 상태를 목표로 갱신하며 별도 게임 버전은 관리하지 않습니다.

확인한 항목별로 다음 정보를 남깁니다.

- 확인일·플랫폼
- 무기명·강화 단계·변질·버프 유무, 축적 수치에 영향을 줄 수 있는 캐릭터 능력치
- 확인한 등급·수치와 스크린샷 등 근거
- 로컬 DB·시드 반영 여부와 운영 반영 여부

확인 후 해당 무기의 시드 SQL과 실제 로컬 DB를 함께 수정하고, 조회 결과를 확인한 다음 해당 항목을 완료로 표시합니다. 시드마다 기존 행의 갱신 정책이 다르므로 시드 수정만으로 현재 DB가 갱신된다고 가정하지 않습니다. 확인이 끝난 항목도 근거와 반영 이력을 남깁니다.
